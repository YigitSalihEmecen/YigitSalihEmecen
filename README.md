## 🔭 What I'm up to

- 🤖 **GIGABOT** at the TU Wien Institute of Production Engineering and Photonic Technologies (IFT): integrating a 5G-connected mobile manipulation platform. Dockerized ROS 2 workspace on an NVIDIA Jetson Thor, drivers for the AMR and the arm, a Gazebo digital twin, and 5G teleoperation with a live 3D view.
- 🇪🇺 **AI.ROBOTECH**: coordinating a seven-partner Erasmus+ project on safe autonomous robotics education with ROS 2.
- 🎓 **Master's** in Manufacturing &amp; Robotics: machine vision, robot learning, robot control, mobile robotics.
- 🎮 **Side quests**: getting a Game Boy emulator to run on an ESP32 with no PSRAM, and a €5 plotter made of 3D-printed parts.

## 🛠️ Projects

| Project | What it is | Stack |
|---|---|---|
| [**PolarBot**](https://github.com/YigitSalihEmecen/PolarBot) | A €5 WiFi plotter with polar kinematics and fully 3D-printed parts. Real-time G-code to polar conversion, backlash compensation and a browser control panel. | ESP8266 · JavaScript |
| [**YellowBoy**](https://github.com/YigitSalihEmecen/YellowBoy) | An optimized Game Boy emulator for the ESP32 that fits ROM banking, frame buffer and emulator state into internal SRAM. Analog audio, SD-card ROM loading. | C++ · ESP32 |
| [**Open LiDAR**](https://github.com/YigitSalihEmecen/Open_LiDAR) | Open source low-cost 360° spinning LiDAR and robot platform. 240 Hz real-time mapping, slip ring removed. Grew out of my [graduation project](https://github.com/YigitSalihEmecen/ToF_2D_Scanning_LiDAR). | Python · C++ |
| [**RANSAC Visualiser**](https://github.com/YigitSalihEmecen/RANSAC_Visualiser) | Shows how RANSAC works on simulated LiDAR point-cloud data. | C# |
| [**Engine Sim**](https://github.com/YigitSalihEmecen/Engine_Sim) · [live](https://yigitsalihemecen.github.io/Engine_Sim/) | A realistic engine sound simulator that runs in your browser. | JavaScript |

| [**Cycloidal Gear Generator**](https://github.com/YigitSalihEmecen/Cycloidal_Gear_Generator) · [live](https://yigitsalihemecen.github.io/Cycloidal_Gear_Generator/) | Design your own cycloidal reduction by tuning every parameter. | JavaScript |
| [**Music Sheet Generator**](https://github.com/YigitSalihEmecen/Music-Sheet-Generator) · [live](https://yigitsalihemecen.github.io/Music-Sheet-Generator/) | Creates 3D-printable custom music box strips. | JavaScript |
